เทคนิค/Skills/Workflow น่าลอง

🛡️ Pattern: “Sandbox Contract per Agent Task” — ใช้เมื่อ agent ต้องรัน command; template: task=fix-test, read=repo, write=src+tests, network=off, secrets=off, git=read-only; verify ด้วย command ที่ควรถูก deny ก่อนเปิดใช้จริง อ้างอิง GitHub sandboxing

🔐 Pattern: “Pre-Push Security Review Gate” — ใช้กับ repo ที่ให้ agent แก้โค้ด; ให้ agent รัน security review ก่อน commit/push และแนบ finding + fix diff ใน PR; caveat: ต้องคุม AI Credits/budget และสิทธิ์ enable feature อ้างอิง GitHub secret detection

🧾 Pattern: “Agent Identity Register” — ใช้กับ workspace agents; เก็บ owner, allowed apps, data scopes, action scopes, audit stream, offboarding path; verify ด้วย access review รายเดือน อ้างอิง Google Gemini agent

🤝 Pattern: “Human Gate After Event Trigger” — ใช้กับ ambient/event agents; event สร้าง draft job, agent สรุป evidence, human approve ก่อน side effect; verify ด้วย trace ที่แยก observed event, agent decision, human approval, system action อ้างอิง AWS AgentCore ambient agents
